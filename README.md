# 声屿 SoundShelf

面向 Final Cut Pro 剪辑工作流的本地 macOS 影音素材库，使用 SwiftUI、AppKit 和 AVFoundation 构建。离线整理、检索和预览音乐、音效与视频素材。

## 功能

- 多维标签筛选、原始目录分类、关键词相关度排序及常用搜索。
- 音频波形、时间点标记和 A/B 区间试听。
- 视频缩略图网格，空格放大预览，方向键连续切换。
- 收藏、备注、重复文件内容校验和来源折叠。
- 项目素材篮、多选、批量标签和原文件拖出。
- 目标应用接收拖拽后，自动归入开始拖动时选定的项目。
- 项目删除二次确认和已删除项目恢复。
- 目录变化检测、离线记录及收藏数据保护。

## 构建与使用

需要 Apple Silicon Mac、macOS 14 或以上，以及 Xcode Command Line Tools。本项目当前使用 Swift 5 语言模式，在 Swift 6.1.2 编译器下验证。

```sh
zsh build.command
open 声屿.app
```

首次运行点击“添加素材目录”，选择自己的素材文件夹。应用索引文件，不搬动原文件。构建生成的 App 记录源码目录位置；移动源码目录后请重新构建。

用户索引、收藏和设置保存在 `~/Library/Application Support/SoundShelf`；波形及视频缩略图保存在 `~/Library/Caches/SoundShelf`。素材篮和常用搜索保存在应用偏好设置中。仓库不含任何媒体素材、个人索引或用户记录。

## FCP 工作流

选择“拖出归入”项目，再按住素材旁的绿色箭头拖到目标应用。取消或未被接收不会加入素材篮；成功复制接收时记录完整原文件引用。A/B 区间仅用于试听，不会裁切导出的文件。

此功能不读取 FCP 工程，也不能判断 FCP 后续是否完成解码导入；通过其他途径加入 FCP 的素材不会自动同步。

## 测试

```sh
zsh Tests/run.command
```

自动归入回归覆盖取消、批量加入、去重、项目选择、保存及项目删除后的处理。FCP 真实跨应用拖入流程仍需人工验证。

## 已知限制

- 分类来自目录与规则，不包含 AI 听辨。
- “收藏备份”尚不包含素材篮和常用搜索。
- 原生文件拖拽的接收回执不等于目标应用最终导入成功。
- App 使用本机临时签名，未进行 Apple Developer ID 签名或公证。
- 部分 AVFoundation 同步 API 有弃用警告，当前构建可用。

本仓库保存应用源码；素材包、音乐和视频的授权由使用者自行管理。
